# AI Skill Navigator

An interactive career transition navigator that helps users explore how their existing skills may transfer to adjacent roles and identify practical next steps for learning.

- **Live prototype:** [https://algorithm-xsdc-1.replit.app](https://algorithm-xsdc-1.replit.app)
- **GitHub repository:** [https://github.com/chenzanxu430-code/AlgorithmX_SDC](https://github.com/chenzanxu430-code/AlgorithmX_SDC)
- **Product demo:** [Watch the demo on YouTube](https://youtu.be/HvcVy-fFXrw)

## Project Overview

People considering a career transition may find it difficult to understand which of their existing skills are transferable, what skills they still need, and which roles could be realistic next steps. Job information is spread across listings and reports, making it challenging to turn that information into a clear learning direction.

AI Skill Navigator provides an interactive way to explore career options. Users enter information about their current role, daily tasks, experience, interests, and skills. The prototype uses this information to present a skills profile, possible adjacent roles, potential skill gaps, and a suggested learning direction.

The project is designed to support exploration and planning. Its recommendations are informational and are not a guarantee of employment or a substitute for professional career advice.

## Key Features

- **Skills profile:** Organizes user-provided skills and experience into a readable profile.
- **Task and skill insights:** Helps users reflect on how their current tasks relate to different skills.
- **Adjacent-role recommendations:** Suggests potential roles related to a user's profile.
- **Skill-gap overview:** Highlights skills that may be useful for exploring a recommended role.
- **Learning direction:** Provides a starting point for planning further learning.
- **Bilingual interface:** Supports Chinese and English.

## How It Works

1. The user enters their current role, daily tasks, experience, interests, and skills.
2. The application evaluates the profile using in-app, rule-based matching logic and curated role and skill information.
3. The interface displays profile insights, adjacent roles, potential skill gaps, and a suggested learning direction.

The running application does not call an external generative AI model or a third-party runtime API. Career recommendations are generated using the application's own logic and curated project data.

## Architecture

The application is built with Next.js App Router, React, and TypeScript. The App Router serves the user interface and application routes. The internal `/api/trends` route provides project trend data to the application. Career insights are generated by in-app rule-based logic using curated role and skill information.

The prototype is deployed on Replit.

## Data Sources

The project uses manually reviewed public job-posting pages from JobStreet Malaysia to inform its role and skill examples. The source inventory and individual listing links are in [docs/data-sources.md](docs/data-sources.md).

Other published reference materials include:

- [The Future of Jobs Report 2025 — World Economic Forum](https://www.weforum.org/publications/the-future-of-jobs-report-2025/)
- [Labour Force Statistics, August 2026 — Department of Statistics Malaysia](https://www.dosm.gov.my/portal-main/release-content/labour-force-statistics-aug2026)
- [Malaysia Digital Economy Blueprint](https://www.mydigital.gov.my/wp-content/uploads/2023/08/Malaysia-Digital-Economy-Blueprint_ENG.pdf)

The job-posting sample is limited and may not represent the entire Malaysian labour market. Source dates, sample coverage, and potential bias should be considered when interpreting the results. The application uses curated project data; it does not fetch these reference sources as live APIs.

## AI and Responsible Use

Generative AI tools assisted with drafting and refining project descriptions and hackathon submission documentation. The team reviewed and adapted AI-assisted material and is responsible for the final project content.

The running application does not use an external generative AI model to generate career recommendations. Its career analysis is based on in-app rule-based logic and curated role, skill, and labour-market information.

## Privacy

The prototype does not require users to log in and does not ask for names or email addresses. Role-related information entered by users is processed by the application to generate career insights. A saved analysis session is kept in the user's browser until the user clears the site data or replaces the saved session.

The application does not send user profiles to an external generative AI model or third-party runtime API. Users should not enter sensitive personal information.

## Limitations

- Results are directional estimates, not hiring probabilities or employment guarantees.
- Role and skill profiles and the job-posting sample are limited.
- Public postings may contain source, sampling, or date-related bias.
- Job requirements may change after source information is collected.
- Broader role coverage and additional user testing are possible areas for future development.

## Running the Project Locally

### Prerequisites

- Node.js 20.9 or later
- npm

### Installation

Clone the repository and install the dependencies from the lockfile:

```bash
git clone https://github.com/chenzanxu430-code/AlgorithmX_SDC.git
cd AlgorithmX_SDC
npm ci
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```

### Type Check

```bash
npm run typecheck
```
